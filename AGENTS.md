This is a Angular project.

* Use **Bun by default** for all development tasks.
* `bun install` for dependencies.
* `bun run <script>` for project scripts.
* `bun run test` for tests.
* `bunx <command>` for one-off binaries.
* Do not use `npm`, `yarn`, or `pnpm` unless explicitly requested.
* Do not commit or push any changes to this repository.
* Do not change the Git username or email configuration.
